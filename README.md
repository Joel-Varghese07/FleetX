# FleetX
A Solution to commercial vehicle management

Download the zip file and extract to C:\
Make sure nodejs is installed:\
run command in terminal: Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned:\
  Installation:\
      open terminal: winget install node.js
Open 2 terminal windows\
  Terminal 1: cd fleetx/backend\
npm run dev\
  Terminal 2: cd fleetx/frontend\
            npm run dev\

  In Browser open: http://localhost:5173
